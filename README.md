# 🎙️ Local AI Live Subtitles & Translator (Honor AI Subtitles Style)

Бесплатное автономное приложение для **живого распознавания и перевода трансляций в реальном времени** (Twitch, YouTube, Discord, браузер, видеоплееры) на базе локальных нейросетей.

Приложение спроектировано по аналогии с **Honor AI Subtitles / Live Captions**:
- 📌 **На экране только субтитры** — плавающий оверлей поверх всех окон (Always-On-Top) в стиле **Liquid Glass**: полупрозрачная «стеклянная» карточка с мягкими бликами и тенью.
- 🗂️ **Всё управление в системном трее** — запуск/остановка, настройки, скрытие субтитров и выход. На экране нет лишних панелей.
- 🖱️ **Полностью интерактивное окно** — клики не проходят сквозь него, окно можно двигать и растягивать за края/углы, как обычное окно Windows.
- 🔊 **Захват любого системного звука (WASAPI Loopback):** работает для всех стримов на Twitch/YouTube без необходимости получать ссылки.
- 🔗 **Захват напрямую по URL:** опциональный режим прямого подключения к трансляции.
- ⚡ **100% Бесплатно и Локально:** не требует платных API, подписок или ключей.

---

### 🛠️ Архитектура

1. **Захват звука (`audio_capture.py`):** захватывает аудиопоток ПК напрямую из динамиков/наушников (WASAPI Loopback) или через `ffmpeg`/`yt-dlp`.
2. **Распознавание речи (`faster-whisper`):** локальная оптимизированная реализация Whisper на CTranslate2.
3. **Локальный перевод (`translator_engine.py`):** OPUS-MT en→ru, конвертированная в CTranslate2 int8 для быстрого CPU-перевода.
4. **Интерфейс (`overlay_ui.py`):** плавающая панель на PyQt6 с поддержкой перетаскивания мышью.

### 📦 Установка и запуск

#### Готовое приложение Windows

Скачайте `LocalLiveSubtitles-Setup-1.0.0.exe` из локальной сборки (`dist/`) и запустите установщик. Он устанавливает приложение вместе с моделями распознавания и перевода; интернет для скачивания моделей при первом запуске не требуется. Приложение рассчитано на Windows x64 и работает локально на CPU.

#### Запуск из исходников

```bash
pip install -r requirements.txt
pip install torch transformers  # только для первичной конвертации OPUS-MT
python scripts/prepare_models.py
python main.py
```

Для сборки моделей из исходников нужна сеть; исходные Marian веса (~300 МБ) скачиваются один раз, затем конвертируются в компактную int8-модель. Во время работы распознавание и перевод выполняются локально через CTranslate2. PyTorch/Transformers не нужны в runtime после подготовки модели. По умолчанию приложение использует CPU, чтобы не зависеть от наличия CUDA DLL.

#### Сборка Windows-приложения и установщика

Требуются Python 3.11, зависимости сборки и Inno Setup 6:

```powershell
pip install -r requirements-dev.txt
winget install -e --id JRSoftware.InnoSetup
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
```

Сборка кладёт портативное приложение в `dist/LocalLiveSubtitles/`, а установщик — в `dist/LocalLiveSubtitles-Setup-1.0.0.exe`. Для пересборки, если модели уже подготовлены, можно передать `-SkipModels`.

#### Дополнительно: ffmpeg для режима «URL стрима»
```bash
winget install Gyan.FFmpeg
```
или через Chocolatey: `choco install ffmpeg`. После установки перезапустите терминал, чтобы `ffmpeg` попал в `PATH`. Для режима **«Системный звук»** ffmpeg не нужен.

#### Проверка окружения из исходников:
```bash
python doctor.py
```
Скрипт покажет версии пакетов, найденные аудиоустройства и инструменты.

#### Сквозной тест исходников (необязательно)

После подготовки моделей можно проверить распознавание и перевод на тестовой WAV-записи:

```bash
python e2e_test.py путь\к\audio.wav base.en
```

Подготовка по умолчанию скачивает Whisper `base.en` и конвертирует OPUS-MT en→ru; исходные веса Marian нужны только на этапе подготовки модели.

#### 5. Запуск приложения:
```bash
python main.py
```

Чтобы сразу начать захват системного звука без нажатия кнопки:
```bash
python main.py --autostart
```

### 🚀 Как пользоваться

1. Запустите приложение — в системном трее появится иконка **CC**, а на экране — только окно субтитров.
2. Включите любую трансляцию на Twitch или YouTube в браузере.
3. **Двойной клик по иконке в трее** (или пункт **«Настройки…»** в контекстном меню) откроет панель управления:
   - **Источник звука** — «Системный звук (Динамики)» или «URL трансляции».
   - **Модель распознавания** — рекомендуется `base.en`.
   - **Устройство захвата** — оставьте **«Авто (активное устройство)»**: приложение само выберет выход, на который сейчас идёт звук. Либо укажите конкретное устройство вручную.
   - **Прозрачность** — 10–100%; значение сохраняется.
4. Нажмите **▶ Запустить** в настройках или выберите **«Запустить»** в меню трея.
5. В установщике модели уже включены. При запуске из исходников их нужно один раз подготовить командой `python scripts/prepare_models.py` (загрузка требует интернет).
6. Субтитры появляются в оверлее. Его можно **перетаскивать за центральную часть** и **растягивать за любой край или угол** (как обычное окно Windows). Размер и позиция запоминаются.
7. Пункт трея **«Скрыть/Показать субтитры»** убирает или возвращает оверлей, не останавливая захват.

**Меню трея:**
| Пункт | Действие |
|-------|----------|
| ▶ Запустить / ⏹ Остановить | Старт и стоп распознавания и перевода |
| Настройки… | Открыть панель управления (также двойной клик по иконке) |
| Скрыть / Показать субтитры | Видимость оверлея без остановки |
| Выход | Полностью закрыть приложение |

> **Совет:** модель `tiny.en` — самая быстрая, `base.en` — баланс, `small.en` — точнее, `medium` — максимальное качество, но заметно медленнее на CPU.

### 🧩 Возможные проблемы

| Проблема | Решение |
|----------|---------|
| `No module named ctranslate2` при запуске из исходников | `pip install -r requirements.txt`, затем `python scripts/prepare_models.py` |
| Нет субтитров | В поле **«Захват звука»** выберите устройство, на которое реально идёт звук (или «Авто»). Убедитесь, что стрим не на паузе |
| Нет субтитров, в логе `[Audio Error]` | Запустите `python doctor.py`, проверьте аудиоустройства |
| `ffmpeg not found` | Установите ffmpeg для режима URL или используйте системный звук |
| Медленно на CPU | Выберите `tiny.en` или `base.en`; GPU-режим доступен при CUDA-совместимой сборке CTranslate2 и настройке `LOCAL_SUBTITLES_DEVICE=cuda` |
| Установленное приложение не запускается | Посмотрите `%LOCALAPPDATA%\LocalLiveSubtitles\logs\app.log` |

### 📁 Структура

```
main.py               — точка входа, контроллер и системный трей
settings_dialog.py    — панель настроек (источник, модель, устройство, прозрачность)
audio_capture.py      — захват системного звука и URL
translator_engine.py  — Whisper STT + OPUS-MT en→ru через CTranslate2
overlay_ui.py         — оверлей субтитров PyQt6 (только субтитры)
doctor.py             — диагностика окружения
e2e_test.py           — сквозной тест STT+перевод на WAV
scripts/prepare_models.py — подготовка локальных моделей
scripts/build.ps1     — сборка приложения и установщика Windows
installer/            — сценарий Inno Setup
requirements.txt      — runtime-зависимости
requirements-dev.txt  — зависимости подготовки моделей и сборки
models/               — локальные модели (не включаются в git)
```
